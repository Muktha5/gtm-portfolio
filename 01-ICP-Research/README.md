# 🎯 ICP Research Framework

> Building a repeatable Ideal Customer Profile (ICP) framework for B2B GTM teams.

---

# 📌 Project Overview

Finding the right customers is one of the biggest challenges in B2B sales.

This project focused on creating a structured process to identify companies that closely match the Ideal Customer Profile (ICP) based on business characteristics, technology stack, geography, company size, and decision-maker roles.

The objective was to improve lead quality and reduce time spent on researching unsuitable prospects.

---

# 🎯 Objectives

- Define the Ideal Customer Profile (ICP)
- Research target accounts
- Filter companies using predefined criteria
- Identify decision makers
- Create a qualified prospect list
