# 🤖 GTM Automation Workflow

> Automating repetitive GTM research tasks using Google Apps Script and workflow automation.

---

# 📌 Business Problem

Manual GTM research involves repetitive tasks such as identifying website technologies, validating companies, updating spreadsheets, and qualifying prospects.

These repetitive activities reduce productivity and increase the possibility of manual errors.

This project focused on automating these research activities to improve efficiency and create scalable GTM workflows.

---

# 🎯 Objectives

- Reduce manual research
- Automate website analysis
- Standardize data collection
- Improve research accuracy
- Support outbound prospecting

---

# 🛠 Technologies

- Google Apps Script
- JavaScript
- Google Sheets
- HTTP Requests
- APIs
- Automation Logic

---

# 🔄 Workflow

```text
Website List
      │
      ▼
Apps Script
      │
      ▼
Website Analysis
      │
      ▼
Technology Detection
      │
      ▼
Update Google Sheet
      │
      ▼
Qualified Prospect Database
```
